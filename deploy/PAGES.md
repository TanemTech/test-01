# Автоматическая первая ссылка

Исходные шаблоны сайтов не меняются. Их workflow `pages.yml` копируется в
клиентский репозиторий вместе с сайтом и его проверками.

ChatGPT создаёт в управляющем `TanemTech/test-01` файл
`deploy/pages/ИМЯ-РЕПОЗИТОРИЯ.json`:

```json
{"repository": "TanemTech/ИМЯ-РЕПОЗИТОРИЯ"}
```

Коммит в main автоматически включает Pages через API, запускает `pages.yml`
клиента и ждёт успешной публикации и доступности HTTPS. Готовая ссылка выводится
как `PAGES_READY` в журнале и в результате Actions. ChatGPT проверяет результат
запуска и передаёт ссылку специалисту. Дальнейшие правки сайта публикуются на этой
же ссылке обычным `push` в клиентский main.

Здесь нет подключения к Selectel, изменений DNS или публикации рабочего сайта.
Записи `deploy/pages/*.json` независимы от `deploy/sites/*.json`.
Создание произвольного пустого репозитория само по себе ничего не публикует.

## Однократный доступ владельца

Токен хранится только в Actions secret управляющего репозитория:
`TANEM_PAGES_TOKEN`. Для совместимости используется `TANEM_GITHUB_TOKEN`, если
отдельного Pages-токена нет. Он должен иметь доступ к нужным клиентским
репозиториям (All repositories включает будущие), права Contents: read,
Actions: write, Pages: write и Administration: write. Последнее требуется API
создания Pages. Не передавать токен в чат и не копировать его в клиентские сайты.

Если прав не хватает, подключение явно завершается ошибкой. После исправления
доступа можно повторить неудачный job либо изменить соответствующий JSON
(например, добавить `"retry": 1`). Ручной запуск workflow повторяет проверку всех
записей; обычный push обрабатывает только добавленные и изменённые записи.

До включения проверяется, что репозиторий публичный, содержит клиентский
`pages.yml`, не является исходным COPY-шаблоном, и что другие workflow не
публикуют что-либо по завершении Pages. Чужой существующий домен Pages не
перенастраивается. Данные клиента должны уже проходить проверки шаблона;
успешная проверка с пропущенной публикацией не считается готовой ссылкой.

Рабочий сайт на Selectel выпускается отдельно и только после разрешения.
